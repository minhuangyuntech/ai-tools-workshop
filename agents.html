02 / AI 應用實作

認識會使用工具的 AI

用「交代需求、取得成果、親自驗收」理解 Agent。

交代目標→安排步驟→使用工具→交付成果→由你驗收

聊天 AI 可以提出答案；Agent 還能在獲得授權的環境裡使用工具，讀取檔案、產生作品或執行多步工作。完成訊息仍需要用實際成果核對。

工具主要用途使用與費用概念
Claude Code（另開分頁）處理專案、修改檔案、執行指令與測試依 Claude 訂閱或 API 等適用方式使用，留意用量。
OpenAI Codex（另開分頁）協助完成程式與專案任務，交付可檢查的檔案不同方案有不同用量；API 費用與聊天訂閱分開。
OpenClaw（另開分頁）自行架設助手，串接通訊管道與工具開源軟體之外，仍可能有模型、主機與服務費。
Hermes Agent（另開分頁）使用工具、記憶與技能執行持續性工作此處指 Nous Research 的 Hermes Agent；需設定執行環境與模型。
Gemini Spark（另開分頁）管理任務、工作流程與排程目前需適用 Google AI Pro／Ultra；與免費聊天 Skills 的條件不同。

API：讓軟體呼叫模型的入口

你在聊天網站輸入文字；程式則透過 API 送出要求。Agent 是執行工作的軟體，模型 API 是它可能使用的服務。

服務或工具角色收費與限制
OpenRouter（另開分頁）多家模型的 API 聚合與路由入口依模型用量與平台費計價；免費模型仍有速率與用量限制。
NVIDIA API Catalog／NIM（另開分頁）模型試用、託管端點與部署途徑依模型與試用資格開放；正式使用或自行部署另有條件與成本。
OpenCode（另開分頁）開源 coding Agent，可連接不同模型供應商主程式與模型費用分開；Zen（另開分頁） 是模型服務，Go（另開分頁） 是訂閱選項。
API key 是服務憑證，請勿放進公開網頁、提示詞截圖或 GitHub repo。API 按量費、聊天訂閱費和持續運作的主機費，可能是三筆不同費用。
在已設定好的 Agent 中使用

把需求交給 Agent

請在本次指定資料夾建立 index.html，製作繁體中文的咖啡店客訴登記示範頁。
包含問題類型、內容與狀態，提供新增按鈕及清單。必填欄位未填時要提醒。
資料暫存在目前頁面，重新整理會清空，請明確標示。
使用虛構資料，不連外部資料庫、不寄訊息、不發布網站。
完成後測試空白送出、正常新增與狀態顯示。
沒測到的部分要列明，交付檔案並說明如何使用。

驗收三件事：空白送出會提醒、填好後真的能新增、顯示的狀態與輸入相符。這個範例是練習原型，尚不具備正式系統的資料保存與權限管理。
