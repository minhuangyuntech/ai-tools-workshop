依序完成練習，或選擇你現在需要的單元。提示詞可以直接複製，教材可以下載帶走。

開始第一個單元
已完成練習0 / 8

工具免費入門

先準備好三個分頁

ChatGPTGeminiNotebookLM

登入自己的帳號，建立「AI課程成果」資料夾。使用 Ctrl＋C／Ctrl＋V 複製貼上；Mac 使用 Command。

本站提供步驟、提示詞及練習素材，AI 生成操作在各工具分頁完成。巷口咖啡資料是虛構情境，研究摘述另有原始來源。

課程單元

01開始練習

AI 工具比較

先用免費功能完成小任務；需要更多用量時，再比較方案。

02開始練習

Agent 與 API

用「交代需求、取得成果、親自驗收」理解 Agent。

03開始練習

提示詞練習

先比較兩種問法，再把提示詞換成自己的工作問題。

04開始練習

生圖與修圖

描述主體、場景與風格，再清楚說明哪些部分要保留。

05開始練習

評論與查核

整理 1–5 星評論，練習查證每一句話。

06開始練習

NotebookLM 作品

用活動企劃做簡報、心智圖、學習卡與資訊圖表。

07開始練習

報告與流程圖

文字先正確，圖形才有用。保留來源與可以再次修改的原始檔。

08開始練習

Gemini Skills

寫清楚何時使用、怎麼做，以及如何檢查。換一份材料，再測一次。

09開始練習

成果與測驗

選一項作品，用一分鐘說明用途與你核對過的內容。

10開始練習

素材下載

下載後放進「AI課程成果」，依每個單元的用途使用。

11開始練習

官方說明

官方產品說明與模擬活動資料是兩種不同來源。
